# VirtuoFlow

Site institucional da [VirtuoFlow](https://virtuoflow.com.br) — Soluções em IA & Tecnologia.

![VirtuoFlow](assets/logo.svg)

- `index.html` — landing page
- `privacidade.html` — política de privacidade
- `assets/` — kit da marca (logo, símbolo, favicon, imagem de compartilhamento)

```bash
docker build -t virtuoflow . && docker run --rm -p 8080:80 virtuoflow
```

Detalhes de estrutura, identidade visual e convenções em [CLAUDE.md](CLAUDE.md).
